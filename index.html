¿Qué es Open Source?

Open Source (código abierto) describe software cuyo código fuente se publica de forma abierta: cualquier persona puede leerlo, usarlo, modificarlo y redistribuirlo. No se trata solo de que el programa sea gratuito — lo central es la transparencia del código y la libertad para intervenir en él.

Este modelo se sostiene en licencias específicas (GPL, MIT, Apache) que definen legalmente qué se puede hacer con ese código, y en comunidades globales que colaboran de forma distribuida sin pertenecer a una misma empresa ni país.

Hoy el Open Source es la base de gran parte de la infraestructura tecnológica global: el servidor que aloja esta página, el navegador con el que la lees, el sistema operativo de tu teléfono — todo tiene raíces en proyectos abiertos. Y la mejor parte: cualquiera puede unirse.

Lo esencial

Las cuatro libertades

La Free Software Foundation las definió para explicar qué hace "libre" a un programa. Toca cada una.

0

Ejecutar el programa para cualquier propósito

Trabajo, escuela, negocio o diversión: no necesitas pedir permiso ni justificar para qué lo usas.

# sin permisos especiales
$ firefox &
$ libreoffice --writer
1

Estudiar cómo funciona y modificarlo

Tener el código fuente permite entender el programa por dentro y adaptarlo a tus necesidades. Es la base de aprender de verdad.

# leer el código del kernel Linux
$ git clone https://github.com/torvalds/linux
$ less linux/kernel/sched/core.c
2

Redistribuir copias para ayudar a otros

Puedes dar o vender copias del programa. Si algo te sirvió, puedes pasárselo a tu compañero, a tu escuela o a tu comunidad.

# pasar una copia en una USB
$ cp -r mi-programa/ /media/usb/
$ echo "listo para compartir"
3

Distribuir copias de tus versiones modificadas

Si mejoras el programa, puedes publicar tu versión para que todos se beneficien. Así nacen las distros derivadas: Ubuntu partió de Debian y Linux Mint de Ubuntu.

# tu propia versión
$ git checkout -b mi-version
$ git commit -m "Mejora para la comunidad"

Historia exprés

De un anuncio a un movimiento global

  1. 1983

    Nace el proyecto GNU

    Richard Stallman anuncia su plan de crear un sistema operativo completamente libre.

  2. 1991

    Llega Linux

    Linus Torvalds anuncia el kernel que, junto a las herramientas GNU, forma el sistema que hoy llamamos Linux.

  3. 1998

    "Open source" y la OSI

    Se populariza el término y se funda la Open Source Initiative para promover el modelo.

  4. 2005

    Nace Git

    Torvalds crea Git para coordinar el desarrollo del kernel: hoy es el control de versiones estándar.

  5. 2008

    GitHub

    Se lanza GitHub y colaborar en código abierto se vuelve cuestión de un clic y un pull request.

  6. 2018

    Microsoft y GitHub

    Microsoft compra GitHub: una señal de cuánto pesa el código abierto incluso en las grandes empresas.

Dudas comunes

Preguntas frecuentes

¿Open Source significa gratis?

No necesariamente. Significa que el código es accesible y puedes usarlo, estudiarlo, modificarlo y redistribuirlo según su licencia. Mucho software abierto es gratuito, pero hay proyectos y empresas que cobran por soporte, alojamiento o versiones comerciales.

¿Es seguro usar software de código abierto?

Que el código sea público permite que más personas lo revisen, pero eso no garantiza por sí solo la seguridad. Lo que importa es que el proyecto esté activo, publique actualizaciones y tenga una comunidad que atienda los problemas.

¿Puedo usarlo en una empresa o en mi negocio?

Casi siempre sí. Solo revisa la licencia: las permisivas (MIT, Apache, BSD) piden poco, y las copyleft como la GPL exigen compartir el código de las versiones derivadas que distribuyas.

¿Cómo contribuyo si no sé programar?

Hay muchas formas: mejorar la documentación, traducir, reportar errores con buen detalle, probar versiones nuevas, diseñar o ayudar a otras personas en foros. Aquí tienes una guía para dar el primer paso.

¿"Software libre" y "open source" son lo mismo?

Describen casi el mismo conjunto de programas, pero con énfasis distinto. "Software libre" (Free Software Foundation, 1985) pone el foco en las libertades de las personas usuarias; "open source" (término popularizado en 1998) destaca las ventajas prácticas de desarrollar el código de forma abierta.
