Apache Software Foundation

Más de 300 proyectos activos. Responsable de Apache HTTP Server, Kafka, Spark, Maven y buena parte del stack de Big Data.

Sitio oficial ↗ ← Volver a Organizaciones

¿Qué hace esta organización?

La ASF nació en 1999 a partir de la comunidad que desarrollaba el servidor web Apache HTTP Server, y hoy es una de las fundaciones de software libre más grandes del mundo. Funciona con un modelo meritocrático: cualquier persona puede ganarse un rol de decisión dentro de un proyecto según sus contribuciones, sin importar a qué empresa pertenezca. Sostiene más de 300 proyectos con licencia Apache 2.0, entre ellos buena parte del stack moderno de procesamiento de datos.
