¿Qué es Open Source?

Open Source (código abierto) describe software cuyo código fuente se publica de forma abierta, de modo que cualquier persona puede leerlo, usarlo, modificarlo y redistribuirlo. No se trata solo de que el programa sea gratuito: lo central es la transparencia del código y la libertad para intervenir sobre él.

Este modelo se sostiene en licencias específicas (como GPL, MIT o Apache) que definen legalmente qué se puede hacer con ese código, y en comunidades de desarrolladores que colaboran de forma distribuida, muchas veces sin pertenecer a una misma empresa ni ubicarse en un mismo país.

Hoy el Open Source es la base de gran parte de la infraestructura tecnológica global: sistemas operativos, lenguajes de programación, frameworks y herramientas de desarrollo se construyen y mantienen bajo este modelo. Y la mejor parte es que cualquiera puede entrar: usarlo, aprender de él o sumarse a construirlo.

Historia

1983

Proyecto GNU

Richard Stallman inicia GNU con el objetivo de crear un sistema operativo completo compuesto enteramente por software libre.

1985

Free Software Foundation

Stallman funda la FSF para dar soporte legal y organizativo al movimiento del software libre.

1991

Nace Linux

Linus Torvalds publica el kernel Linux, que combinado con las herramientas de GNU da origen a un sistema operativo libre completo.

1998

Se acuña "Open Source"

Tras la publicación del código de Netscape, se funda la Open Source Initiative (OSI) para facilitar la adopción comercial del modelo.

2005

Git

Torvalds crea Git, un sistema de control de versiones distribuido que cambiaría la forma de colaborar en proyectos de código.

2008

GitHub

El lanzamiento de GitHub simplifica alojar, compartir y contribuir a proyectos, acelerando la colaboración masiva a escala global.

Hoy

Un ecosistema consolidado

Proyectos como Linux, Python, Kubernetes o Visual Studio Code sostienen hoy buena parte de la industria del software.
