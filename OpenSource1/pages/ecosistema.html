Fundación

¿Qué es Open Source?

Open Source (código abierto) describe software cuyo código fuente se publica de forma abierta: cualquier persona puede leerlo, usarlo, modificarlo y redistribuirlo. No se trata solo de que el programa sea gratuito — lo central es la transparencia del código y la libertad para intervenir en él.

Este modelo se sostiene en licencias específicas (GPL, MIT, Apache) que definen legalmente qué se puede hacer con ese código, y en comunidades globales que colaboran de forma distribuida sin pertenecer a una misma empresa ni país.

Hoy el Open Source es la base de gran parte de la infraestructura tecnológica global: el servidor que aloja esta página, el navegador con el que la lees, el sistema operativo de tu teléfono — todo tiene raíces en proyectos abiertos. Y la mejor parte: cualquiera puede unirse.

Historia

1983

Proyecto GNU

Richard Stallman inicia GNU con el objetivo de crear un sistema operativo completo compuesto enteramente por software libre.

1985

Free Software Foundation

Stallman funda la FSF para dar soporte legal y organizativo al movimiento del software libre y publicar las licencias GPL.

1991

Nace Linux

Linus Torvalds publica el kernel Linux. Combinado con las herramientas de GNU, da origen a un sistema operativo libre completo que hoy corre en servidores, teléfonos y supercomputadoras.

1998

Se acuña "Open Source"

Tras la publicación del código de Netscape, se funda la Open Source Initiative (OSI) para facilitar la adopción comercial del modelo.

2005

Git

Torvalds crea Git, el sistema de control de versiones distribuido que cambiaría para siempre la forma de colaborar en proyectos de código.

2008

GitHub

El lanzamiento de GitHub simplifica alojar, compartir y contribuir a proyectos, acelerando la colaboración masiva a escala global.

Hoy

Un ecosistema consolidado

Linux, Python, Kubernetes, VS Code, Android y miles de proyectos más sostienen la industria del software mundial — todos abiertos, todos accesibles.
