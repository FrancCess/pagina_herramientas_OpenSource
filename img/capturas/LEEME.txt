CAPTURAS DE PANTALLA — GUÍA RÁPIDA
========================================

Cada ficha de herramienta tiene 3 recuadros reservados para capturas
de pantalla del software. Para agregar las tuyas:

1. Guardá cada imagen en esta misma carpeta (img/capturas/) con el
   nombre exacto que aparece en la lista de abajo (ej: git-1.jpg).
   Podés usar .jpg o .png -- si usás .png, cambiá la extensión en el
   código HTML de la página correspondiente (buscá el comentario
   <!-- CAPTURA N de ... --> justo arriba de cada recuadro; ahí está
   el código ya armado, listo para copiar y pegar).

2. Reemplazá el <div class="shot-item">...</div> del placeholder por
   el <div class="shot-item"><img ...></div> que indica ese comentario.

3. Tamaño recomendado: ~900x600px (proporción 4:3), para que se vean
   nítidas sin pesar demasiado. No hace falta que sea exacto: la imagen
   se recorta sola para llenar el recuadro (object-fit: cover).

No hace falta completar las 3 capturas de cada herramienta -- las que
dejes sin imagen se quedan con el recuadro punteado, sin romper nada.
